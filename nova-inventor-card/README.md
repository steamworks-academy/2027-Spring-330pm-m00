# Nova's Inventor Card

One-page, letter-size inventor card for the fictional kid Nova.

- Main file: `nova-inventor-card.svg`
- Page size: 8.5 × 11 inches at 96 DPI
- Includes three imaginary inventions, a favorite color palette, and a friendly robot badge.

Open the SVG in a browser to view or print it. The artwork is vector-based, so it stays sharp when enlarged.
