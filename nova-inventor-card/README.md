# Nova's Inventor Card

One-page inventor cards for the fictional kid Nova.

- `nova-inventor-card.svg` — editable letter-size vector card with Cloud-Pocket Backpack, Glow-Go Sneakers, and Snack-Saver Bot.
- `nova-inventor-card-v2.png` — new 1024 × 1536 illustrated card with Puddle Jumper Boots, Dream-Doodle Projector, and Kindness Compass.
- Both versions include three imaginary inventions, a favorite color palette, and a friendly robot badge.

Open either file to view or print it. The SVG stays sharp when enlarged; the PNG is ready to share as an image.
